# Happytime 文案口径与灵感池

## 文案格式（照抄 app 的口径，别自创风格）

输出一个 JSON：`{"title":"短语 time","copy":"2~3句话的文案"}`

- **title**：2~6 个字的短语 + ` time`，中间留一个空格。例：`闪闪发光 time`、`友情加载 time`、`能量满格 time`、`勇气爆发 time`。要贴合这件开心事的主题（运动 / 友谊 / 学习 / 创造 / 勇气 / 美食…），不要重复灵感池里已有的短语。
- **copy**：2~3 个短句，合计 40~70 字，用「你」称呼孩子，温暖、具体、有画面感，像爸爸妈妈念给孩子听的话。第一句点出画面，第二句夸赞 / 送上祝福，第三句可有可无。**不要说教**。
- 全部简体中文。贺卡上正文最多排 3 行，超过会被降字号。

## 麦乐漫记题字（有照片时才有）

在 Happytime 文案之后，再写一套「漫记文字」，输出 `{"title":"标题","text":"题字","scenes":{"panel1":"…","panel3":"…"}}`：

- **title**：4~10 字短标题，像明信片题名，有画面感、有温度；不出现「时间」「记录」这类词。上限 12 字。
- **text**：题字，**上限 44 字**，用「你」称呼孩子，把「今天这件开心事」和「选的这份餐」自然串成一句。不要分点、不要说教、不要堆感叹号。
- **scenes.panel1**：照片里孩子今天最高光瞬间的一句话描述（≤60 字，给图像生成用）。
- **scenes.panel3**：孩子享用这份餐的场景描述（≤60 字）。
- 失败兜底：直接用 Happytime 的 title（去尾缀后加「的一天」）与 copy。

## 灵感池维护

改文案后注意两件事：① 每条 chip 文案 ≤ 11 字；② 每页 chips 合计 ≤ 33 字（窄屏不溢出，并排展示用）。4 条一页，第 4 条与「换一换」同排。
