# v4 视觉规范（手绘绘本风）

v4 的产出物有**两件**，别混：**① Happytime 贺卡**（16:9 横版，纯文字卡，随时可出）与 **② 麦乐漫记**（3:4 竖版，需要照片）。两件都用「手绘 / 纸质感」语言，不出现现代扁平 UI。

---

## 一、Happytime 贺卡（16:9，逻辑 1200 × 675）

模板：`templates/happytime-card-template.html`（已按 0.5 缩放显示，交付高清整体 ×2）。

### 背景（三选一，按文案气氛挑）

| 文件 | 画面 | 适配气氛 |
|---|---|---|
| `assets/bg-flower-frame.jpg` | 花草边框 + 白色留白中心（纸飞机/兔子/放风筝的孩子） | 通用、安静的小确幸（默认） |
| `assets/bg-hill-run.jpg` | 山丘草地 + 奔跑孩子 + 兔子 | 运动、比赛、撒欢 |
| `assets/bg-kite-meadow.jpg` | 风筝蒲公英草原 | 自由、探索、交朋友 |

### 排版规则（照抄 app 的 Canvas 逻辑，不要自由发挥）

- **中央暖白晕**：`radial-gradient` 56%×70% @ (50%, 46%)，`rgba(255,254,250,.55) → .32 → 0`，给标题正文让出可读区，边缘插画不动。
- **标题**：砖红 `#c0281f`，逻辑字号 118px，**占画面宽度上限 58%**；字距 `0.12em`；**只填充、不描边**——深色描边会把粗笔画之间的空隙填死；手写感靠字距 + 轻微旋转（每字 ±1.6px 起伏、±0.025rad 旋转），**不靠加粗**（站酷快乐体只有一个字重，写 bold 会合成加粗、笔画粘连）。
- **正文**：黑墨 `#3a352e`，字号按长度自适应（≤16 字 56px / ≤38 字 50px / 其余 44px，再统一 ×0.9）；行高 1.68；左起 x=220、宽 1200-440；**紧跟标题下沿 44px**（不要在中部垂直居中，会甩出一大段空白）；最多 3 行，超了降到 40px。
- **整块微倾**：正文整体 `rotate(-0.011rad)`，逐行 ±2.2px 起伏、±3px 横移，做出手写呼吸感。
- **圆角** 38px。

### 关键词彩色（命中即染色，最长优先）

| 词 | 色 | 词 | 色 |
|---|---|---|---|
| 阳光 / 星星 / 发光 / 闪亮 / 得意 / 主角 / 大笑 / 宝藏 | `#e0b93f` | 耀眼 / 勇敢 / 击掌 / 微笑 / 升级 / 庆祝 / 拥抱 | `#e2603c` |

模板内置同款染色脚本（加载时自动包 span），改色表时与 app 的 `KEYWORD_COLORS` 同步。

## 二、麦乐漫记（3:4，逻辑 1080 × 1440）

### 首选：一次出整张（图生图）

参考照片里的人物，一次生成整张「麦乐记」手账拼贴插画。提示词骨架（与 app 的 `plugins/qwen-style.mjs` 的 `postcardPrompt` 一致）：

```
参考这张照片里的人物，画一张完整的「麦乐记」手账拼贴插画，竖版 3:4 构图，{风格}，画面温暖明亮：
上方并排两格漫画——左格：{孩子的高光时刻描述}，主角就是照片里这个孩子，格子底部贴一块浅米色
牛皮纸质感的纸片，纸片上用圆润胖乎乎、俏皮快乐的手写 POP 体（像「站酷快乐体」）写「{Happytime 标题}」；
右格：把「{餐品名}」摆在温馨的木桌上，麦当劳风格的红色包装盒，这格里不要出现任何文字、字母或数字；
下方是一张占画面下半部的大图：{孩子享用这份餐的场景}，在这张大图的右上角贴一条浅米色牛皮纸质感的
小纸条，纸条上用黑色稚拙的手写字体（像小朋友写的字，笔画歪歪扭扭、大小不一）写「{漫记标题}」；
画面最下方是一条浅米色牛皮纸的纸带（高约占画面五分之一），纸带上用同样的稚拙手写体写一句话，
分两到三行居中排列（文字避开纸带左下角和右下角），字迹清清楚楚、一笔不差、每个字都完整可读：「{题字}」；
整张插画保持浅米色牛皮纸的手账质感与童趣氛围。严格保留照片里这个孩子的相貌与发型特征。
重要：整张画面里只能出现上面写明的文字，不要出现任何其他文字、字母、数字、水印或签名。
```

- 风格档（按气氛选）：`anime` 日本动画电影 / `ghibli` 吉卜力（默认）/ `pixar` 皮克斯 3D。
- 长度上限：**漫记标题 ≤12 字、题字 ≤44 字**（实测 44 字模型能写全，越长错字率越高）、Happytime 标题 ≤16 字、餐品名 ≤20 字、场景描述各 ≤60 字。
- 负向词：`畸变，多余手指，模糊，低质量，写实照片质感，错别字，多余文字，印刷体，水印`。
- 生成后**程序只补两样**模型画不稳的东西：右下角「麦乐记」字标（正片叠底、底边距卡底 350px）+ 左下角日期（`YYYY.MM.DD · 麦乐漫记`，加一圈纸带色描边压住任何底色）。
- 已知风险：模型偶有错字（画面里任何自造文字都可能错）——如实告知用户，错了就重新生成一版。

### 兜底：本地版式（模板）

模板：`templates/postcard-template.html`（照片 + 牛皮纸纸带题字 + 字标 + 日期）。

- 纸带：`BAND_TOP = 1440-320`，暖米渐变 `#F5EDD6 → #EADCB6`，上沿撕纸毛边 + 稀疏纸纹噪点 + 顶部柔和投影。
- 题字：左起 `PAD+20=64`，字号 42px 起逐级降级 `38/34/30/26`，保底再压行距——**一字不差是交付标准**，绝不截断、绝不打省略号；行首禁则 `，。！？；、：…·」』）)]”’”` 不出现在行首（挂到上一行行尾）。
- 照片区：`PAD=44`，宽 992，高 1036，圆角 30，浅边 `#EBE2CF`。
- 漫记标题：白色手写体压在照片右上角（右缘内 40），暖棕描边 + 投影，亮/暗照片都读得清。

## 四、界面质感（做 HTML 页面时）

- 蜡笔卡片：`border-radius: 20px 16px 22px 18px`（四角故意不一致）+ 硬阴影 `3px 4px 0 hsl(30 25% 45% / .1)`；卡片轻歪 ±0.35°。
- 半透明胶带：74×22，`hsl(46 90% 62% / .42)`，贴卡片角，±6°。
- 品牌红 `#DA291C`、品牌黄 `#FFC72C`、奶油 `#FAF3E2`、墨 `#3B3730`、浅棕 `#A79A82`、发丝线 `#EBE2CF`。
- 分隔用蜡笔波浪线 / 涂鸦，不用规整直线。
