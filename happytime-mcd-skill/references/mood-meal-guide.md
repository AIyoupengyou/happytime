# 心情选餐策略

目标：从 MCP 返回的**真实餐品清单**里，挑一个最贴合今天开心事气氛的。绝不允许清单外编造。

## 气氛 → 餐品方向映射

| 开心事的气氛 | 选品方向 | 举例标签 |
|---|---|---|
| 赢了比赛 / 得到表扬 | 有庆祝感的：堡类主食 + 甜品组合 | 牛肉、甜品 |
| 累了一天 / 坚持完成一件事 | 能补能量的：主食 + 热饮 | 主食、热 |
| 和朋友一起玩 | 适合分享的：分享装、多份小食 | 分享、鸡肉 |
| 下雨天 / 天冷 | 暖暖的：热粥、热咖啡、热茶 | 热 |
| 学会新本领 / 尝试新事物 | 有新鲜感的：当季新品、新口味 | 新品标签优先 |
| 安静的小确幸 | 清爽小份：沙拉、玉米杯、牛奶 | 清爽 |
| 大汗淋漓的运动日 | 解渴 + 补水：饮品 + 小食 | 冰、清爽 |

## 选品规则

1. 候选必须同时满足：在售菜单里有 code（价格可展示为空但要有营养数据）。
2. 标签匹配优先：MCP 返回的 `tags` > 名称关键词推断（牛肉/鸡肉/鱼/猪/冰/热/甜/分享/清爽）。
3. **优先从有本地产品插画的单品里挑**（`assets/products/{餐品编码}.png`）——推荐卡和漫记画面更完整；没有插画的单品只在清单极窄时才用。
4. 同类用过就换：用户说「换一个」时排除已推荐的，且换分类。
5. 推荐理由写法：
   - 20~35 个字，用「你」称呼孩子，具体、有画面感；
   - 结尾顺带一句和这份餐品有关的营养小知识（见 nutrition-guide.md）；
   - 不说教、不堆感叹号。
   - 例：「今天就点它吧，安格斯牛肉饼厚厚一块，吃饱了才有力气继续当小英雄。」

## 营养卡联动

- 推荐确定后，把该餐品六项营养按每日参考值折算成百分比，画成进度条。
- 参考值口径为 7~10 岁小学生量级，展示时注明「直觉参考，不是膳食建议」。
